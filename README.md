# Mine vs Rock Prediction using Sonar Data

## Objective
Predict whether an object is a Mine or Rock using sonar signal data using Machine Learning.

## Machine Learning Algorithm
- Logistic Regression

## Libraries Used
- NumPy
- Pandas
- Scikit-learn

## Workflow
1. Data Collection
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Prediction
6. Accuracy Evaluation

## Accuracy
- Training Accuracy: 83%
- Testing Accuracy: 76%

## Project Type
Binary Classification Problem

## Dataset
Sonar dataset containing 60 numerical features used to classify objects as Mine (M) or Rock (R).
